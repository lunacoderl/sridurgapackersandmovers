# System Architecture — Sridurga Packers & Movers

## High-Level Paradigm
- Pure Frontend Static Architecture: Zero database, zero runtime API, zero server actions.
- Dynamic URLs via `generateStaticParams()` at build time.
- Dynamic metadata via `generateMetadata()` per service route.
- Interactive booking via client-side structured WhatsApp query builder (wa.me/918500144488).
- CSS: Tailwind CSS v4 + Design Tokens (--brand-primary: #EA580C, --brand-dark: #0F172A).
- Motion: GSAP 3 with ScrollTrigger for desktop horizontal slider & timeline, Framer Motion for interactive UI elements.
