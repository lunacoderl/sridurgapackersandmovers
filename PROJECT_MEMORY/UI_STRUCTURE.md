# UI Structure & Route Inventory

## Primary Marketing Routes
- `/` — Home Page (15 layered sections)
- `/about` — Long-form brand narrative (12 sections)
- `/services` — Services Hub (15 sections)
- `/services/[slug]` — Unified Service Detail Engine (10 sections)
- `/contact` — High-conversion inquiry & contact page (12 sections)

## Utility & Legal Routes
- `/privacy-policy`
- `/terms-and-conditions`
- `/not-found` (404 with custom moving truck animation)
- `/sitemap.xml` (via sitemap.ts)
- `/robots.txt` (via robots.ts)
